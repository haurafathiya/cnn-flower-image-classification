# Flower Image Classification using CNN

## Overview
This project develops a Convolutional Neural Network (CNN) to classify five flower species using TensorFlow.

## Dataset
TensorFlow Flower Photos Dataset

## Tools
- Python
- TensorFlow
- Keras
- Google Colab

## Model
- CNN
- Data Augmentation
- Adam Optimizer
- Sparse Categorical Crossentropy

## Results
- Accuracy: 71%
- Precision: 72%
- Macro Recall: 69%

## Future Improvements
- Transfer Learning (MobileNetV2, EfficientNet)
- EarlyStopping
- More balanced dataset
